## Reproduce the research data

After importing the authorized Ringmast4r snapshot and creating the stable research
queue, apply the current JSON files in `research/profiles/` through the existing
local research command. The JSON files, including pending audit corrections, are
the source of truth. SQLite is local storage and is not committed.

```sh
for file in research/profiles/*.json; do
  npm run research -- --action apply --file "$file" || break
done
npm run research -- --action report --output research/report.json
npm run validate
```

Do not regenerate profiles by filling identity flags from imported rows. Review
must precede publication. In particular, office addresses, multi-tenant buildings,
campus totals, planned capacity and apparent power (MVA) require separate treatment.
