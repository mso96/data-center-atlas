# Data Center Atlas

Phase 1 foundation: a minimal dark application shell, fictional demo repository,
and installed (unmounted) map component.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. Run `npm run validate` for lint, type checking,
repository tests, and a production build. Node 22+ and npm are required.

See [PROJECT_PLAN.md](PROJECT_PLAN.md) for architecture, contracts, limitations,
and the explicitly deferred Phase 2 and Phase 3 scope.
